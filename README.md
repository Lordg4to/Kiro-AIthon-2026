# 🌱 Avanza conmigo

**Compañera de estudio para estudiantes que avanzan lentamente o han interrumpido sus estudios.**

Proyecto de acompañamiento académico presentado como parte del trabajo del equipo T025 en la Kiro IAthon 2026.

## Demo

[Ver Avanza conmigo en Netlify](https://gleeful-narwhal-09923e.netlify.app/)

## Funcionalidades

- Registro de estado de ánimo y notas personales.
- Plan de estudio adaptado al ánimo y al tiempo disponible mediante reglas predefinidas.
- Temporizador de concentración y descanso.
- Registro de sesiones, progreso y constancia.
- Diario personal y recursos de apoyo.
- Almacenamiento local en el navegador (`localStorage`).

## Tecnologías

HTML5, CSS3 y JavaScript (sin frameworks ni servidor).

## Cómo ejecutar

Descarga el repositorio y abre `index.html` en tu navegador. Los archivos `index.html`, `app.js` y `styles.css` deben permanecer en la misma carpeta.

## Publicación en GitHub Pages

En GitHub, abre **Settings → Pages**, elige **Deploy from a branch**, selecciona `main` y la carpeta `/ (root)`, y guarda.

> **Nota:** Esta versión genera planes con reglas locales predefinidas; no utiliza un modelo de IA generativa ni un backend AWS. Los datos se almacenan en el navegador del usuario y no se sincronizan entre dispositivos.

La aplicación es una herramienta de acompañamiento y no sustituye la atención profesional.
